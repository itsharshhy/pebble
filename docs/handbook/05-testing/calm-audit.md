# Calm Audit
*Phase: Testing · The emotional quality gate. A feature fails if **any** answer is "No".*

Run this for every screen a change touches. Takes about 3 minutes. Record the result in the Issue.

| # | Question | Why it matters |
|---|---|---|
| 1 | Can a first-time user finish the main task **without reading instructions**? | Confusion creates anxiety |
| 2 | Is there **exactly one** main (filled) action on screen? | Competing actions create pressure |
| 3 | Are there **3 or fewer** primary choices? | Choice overload slows and stresses ([S11](../00-foundation/science.md#s11)) |
| 4 | Is **every word** kind, with no guilt, urgency or blame? ([Content](../03-design/content-and-voice.md)) | Words land hardest on tired minds |
| 5 | Is there **no red, no flashing, no count of missed things**? | Alarm signals |
| 6 | With reduced motion on, does **only opacity** change? | Motion sensitivity |
| 7 | Does the flow **end in a step forward**: a plan, a release, or done? | Open loops feed rumination ([S7](../00-foundation/science.md#s7)) |
| 8 | Would you show this screen to **someone having a bad day**? | The final test |

## Red flags (instant fail)
Streak · badge · confetti · countdown · "overdue" · "you missed" · red counter · auto-playing
sound · pop-up asking for a rating · infinite scroll · comparison with other users.

## How to run it well
- Do it **in the evening** in the evening palette, since that's when Pebble is most used.
- Read every word **out loud**. Harsh words become obvious when spoken.
- Ask: "If I were already anxious, what on this screen would I notice first?"
